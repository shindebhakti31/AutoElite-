# AutoElite – Premium Car Showroom

AutoElite is a premium car showroom website designed to showcase luxury, SUV and sports cars with a modern and attractive interface.

## Project Description

This project is created as a CSS Mini Project. It uses a premium black and gold theme to provide a stylish car showroom experience.

## Features

- Premium Home Page
- Hero Section
- Cars Collection
- Luxury Cars
- SUV Cars
- Sports Cars
- Car Comparison
- About Us Page
- Contact Page
- Responsive Design
- Hover Effects
- Premium Black and Gold Theme

## Cars Included

- Mercedes-AMG G 63
- Range Rover
- Land Rover Defender 110
- Mahindra Thar
- Porsche 911 GT3 RS
- Lamborghini Revuelto
- Ford Mustang GT
- BMW M4 Competition

## Technologies Used

- HTML5
- CSS3
